## Русский

В версии 1.9 упрощён главный экран:

- кнопка перехода в настройки специальных возможностей показывается только тогда, когда служба Voice Search Router выключена;
- при включённой службе отображается только её состояние без дублирующей кнопки;
- раздел обновлений перенесён в конец настроек, после списка приложений.

Этот релиз также позволяет проверить обновление с версии 1.8 непосредственно в приложении.

## English

Version 1.9 simplifies the main screen:

- the accessibility settings button is shown only while the Voice Search Router service is disabled;
- when the service is enabled, only its status is displayed without a duplicate button;
- the updates section now appears after the application list.

This release can also be used to test the in-app update flow from version 1.8.
