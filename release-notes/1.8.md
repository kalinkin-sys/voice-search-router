## Русский

В версии 1.8 добавлено безопасное самообновление:

- автоматическая проверка GitHub Releases раз в сутки;
- ручная кнопка «Проверить сейчас»;
- уведомление и карточка в приложении, когда доступна новая версия;
- загрузка APK с проверкой SHA-256 и подписи приложения;
- переход в системный установщик Android для подтверждения обновления.

Полностью автоматическая установка без подтверждения пользователя намеренно не используется.

## English

Version 1.8 adds secure in-app updates:

- automatic daily checks against GitHub Releases;
- a manual **Check now** action;
- an Android notification and in-app prompt when a new version is available;
- APK download with SHA-256 and signing-certificate verification;
- hand-off to the Android package installer for user confirmation.

Silent installation is intentionally not used.
