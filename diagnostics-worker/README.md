# Diagnostics Worker

Исходник Cloudflare Worker, через который Voice Search Router отправляет
диагностические отчёты разработчику.

Каталог опубликован для аудита обработки данных. Android-приложение уже использует
работающий экземпляр Worker; самостоятельное развёртывание не требуется.

`wrangler.jsonc` повторяет структуру рабочего конфига, включая почтовую привязку,
ограничения частоты запросов и observability. Личные адреса заменены безопасными
значениями-примерами.
