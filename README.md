# Voice Search Router

Voice Search Router перенаправляет голосовые запросы, распознанные системным
ассистентом Android TV, в поиск выбранного приложения.

Проект появился как решение проблемы Nvidia Shield: аппаратная кнопка микрофона
на пульте работает в системном лаунчере, но голосовой поиск в некоторых сторонних
приложениях — например, SmartTube и KinoPub — не получает распознанный текст.

## Возможности

- Перенаправление голосового запроса в активное приложение.
- Выбор приложений, в которых должна работать маршрутизация.
- Выбор приложения по умолчанию.
- Сохранение штатного поиска Android TV, если приложение по умолчанию не выбрано.
- Специальная поддержка SmartTube и KinoPub.
- Универсальный режим для остальных Android TV-приложений.
- Русский и английский интерфейс с автоматическим определением системного языка.
- Отправка диагностического отчёта разработчику.
- Работа без root-доступа.

## Как это работает

1. Пользователь нажимает аппаратную кнопку микрофона на пульте.
2. Системный Assistant Android TV распознаёт речь.
3. Voice Search Router получает распознанный текст через службу специальных возможностей.
4. Если открыто выбранное в настройках приложение, запрос возвращается в его поиск.
5. Если активное приложение не выбрано, открывается приложение по умолчанию.
6. Если приложение по умолчанию не задано, запрос остаётся в штатном поиске Android TV.

## Установка

1. Скачайте APK со страницы [Releases](../../releases/latest).
2. Установите его на Android TV или Nvidia Shield:

```bash
adb install VoiceSearchRouter.apk
```

3. Запустите Voice Search Router.
4. Нажмите «Открыть настройки».
5. Включите службу `Voice Search Router` в разделе специальных возможностей.
6. Выберите приложение по умолчанию.
7. Отметьте приложения, куда нужно возвращать голосовые запросы, когда они активны.

На Nvidia Shield путь обычно выглядит так:

```text
Настройки устройства → Специальные возможности → Voice Search Router
```

## Поддерживаемые приложения

Отдельная логика маршрутизации реализована для:

- SmartTube;
- KinoPub.

Для остальных приложений используется универсальный режим. Он ищет доступную
поисковую строку и элементы поиска через Android Accessibility API. Результат
зависит от того, предоставляет ли конкретное приложение свои элементы интерфейса
службе специальных возможностей.

## Важное ограничение

Voice Search Router обрабатывает запросы, запущенные аппаратной кнопкой микрофона
на пульте.

Приложение не исправляет собственные экранные кнопки голосового поиска внутри
сторонних программ. Такие кнопки используют реализацию распознавания речи самого
приложения. На Nvidia Shield некоторые из этих реализаций не получают звук с
Bluetooth-микрофона пульта из-за особенностей системного голосового сервиса.

## Диагностика и конфиденциальность

В приложении есть кнопка отправки диагностического отчёта. Отчёт содержит модель
устройства, версии Android и приложений, настройки маршрутизации и последние
технические события Router.

В отчёт не входят распознанные поисковые фразы, звук с микрофона, пароли,
содержимое поисковых полей и другие пользовательские данные. Подробнее — в
[политике конфиденциальности](PRIVACY.md).

Voice Search Router отправляет отчёты через работающий Cloudflare Worker проекта.
Его исходный код и безопасная копия конфигурации находятся в каталоге
[`diagnostics-worker`](diagnostics-worker) и опубликованы для аудита обработки
данных. Приложение уже настроено на действующий сервис — самостоятельно
развёртывать Worker не требуется.

Worker принимает только диагностические отчёты Router, ограничивает размер и
частоту запросов и отправляет их только на заранее заданный адрес. Его нельзя
использовать как произвольное почтовое реле.

## Сборка приложения

Требования:

- JDK 17;
- Android SDK 35;
- Android Build Tools 35;
- Gradle 8.9 или совместимая версия.

```bash
gradle :app:assembleDebug
```

Готовый APK появится в `app/build/outputs/apk/debug/`.
